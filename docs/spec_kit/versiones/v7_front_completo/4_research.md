# Decisiones — Versión 7

## D1 — ¿12 copias del molde o un registro de metadatos?
**Opciones:** (a) copiar las vistas de producto 11 veces · (b) registro +
vistas genéricas. **Decisión: (b)** — repetir el molde en el front no
enseña nada nuevo; el registro enseña un patrón real (configuración
sobre código). Producto conserva sus vistas explícitas de la v6 como
pieza didáctica del molde.

## D2 — ¿Autorización en el front o en la API?
El front oculta y rebota por usabilidad, pero la fuente es la API
(rol_usuario). La API aún no exige token: deuda declarada del curso.
El front nunca decide quién es admin — lo pregunta.

## D3 — ¿Por qué los puentes no se editan?
Regla de la v3: una asignación se quita y se pone. La UI también
obedece las specs.
